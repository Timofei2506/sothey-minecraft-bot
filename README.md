# Sothey · Minecraft 1.12.2

Один бот **Sothey** для `exvxeldo.de5.net`, Minecraft Java **1.12.2**.
Фактический порт сервера — **21734** (проверен через DNS SRV).

## Что делает

- Подключается как `Sothey` и проходит серверную регистрацию/вход.
- Стоит на месте; стандартные пакеты Minecraft поддерживают соединение.
- При сетевом обрыве переподключается с задержкой 15–120 секунд.
- После смерти использует обычное возрождение клиента.
- Завершается по таймеру, при ошибке пароля, бане, whitelist/captcha или запрете простоя.
- Не обходит антибот-защиту, не меняет ник, не спамит движениями/чатом и не играет за пользователя.
- Не записывает пароль и разговоры других игроков в публичные логи.

## Запуск в GitHub Actions

Репозиторий: <https://github.com/Timofei2506/sothey-minecraft-bot>

1. Открой **Actions → Sothey — manual session → Run workflow**.
2. Выбери режим:
   - **check** — двухминутная проверка подключения, входа и присутствия в мире;
   - **night** — две последовательные сессии по **4 часа**, суммарно около **8 часов**.
3. Для остановки открой текущий запуск и нажми **Cancel workflow**.

Запуски только ручные: нет скрытого расписания или бесконечного самоперезапуска.
Одновременно работает максимум один клиент. Между четырёхчасовыми сессиями будет
перерыв на завершение job, очередь runner и установку зависимостей. Время очереди
GitHub не гарантирует; это не непрерывный 24/7-хостинг.

### Важные ограничения GitHub

В публичном репозитории минуты **стандартных** GitHub-hosted runners бесплатны.
Но **каждая задача всё равно ограничена шестью часами**. Размер/число задач,
политики использования и доступность runner также ограничены.

Правила GitHub ограничивают использование hosted runners разработкой, тестированием,

хостинга может привести к остановке задач, ограничениям Actions или аккаунта.
Для надёжной ночной работы предпочтительнее собственный компьютер/VPS.

## Пароли и доступ

Сервер использует offline-mode и собственную авторизацию `/register` / `/login`.
Пароль бота хранится в **Settings → Secrets and variables → Actions → MC_PASSWORD**.
Он не находится в исходниках, workflow или истории Git.
Для первичной настройки создаётся отдельный случайный пароль; GitHub показывает
только имя секрета, не его значение.

Workflow получает встроенный `GITHUB_TOKEN` только с правом `contents: read`;
предоставленный для настройки личный GitHub PAT **не нужен** при работе бота.
После настройки отзови раскрытый PAT в настройках GitHub: это не остановит бота.

Если меняешь `MC_PASSWORD` после регистрации, сначала измени пароль аккаунта на
самом Minecraft-сервере. Изменение одного секрета не меняет серверный пароль.
Не запускай второй клиент под тем же ником одновременно.

## Как проверяется работа

`Code checks` выполняет синтаксическую проверку, unit-тесты и проверку зависимостей.
Режим `check` запускает настоящего клиента на runner GitHub и требует не менее
60 секунд подтверждённого присутствия **после успешной серверной авторизации**.
Одного TCP-соединения или сообщения `joined the game` для успеха недостаточно.

В логе ищи события `AUTHENTICATED`, затем `READY`, затем `HEARTBEAT` с `ready: true`.
По завершении публикуются итоговый JSON и краткая сводка с `readySeconds`.
Короткая успешная проверка не гарантирует доступность сервера и Actions всю ночь.

## Локальный запуск / VPS

Нужен **Node.js 22 LTS**.

```bash
npm ci --ignore-scripts
cp .env.example .env
# Укажи пароль аккаунта Sothey в .env. Не публикуй этот файл.
node --env-file=.env src/main.js
```

Чтобы локально запустить на восемь часов, установи в `.env`:

```dotenv
BOT_RUN_SECONDS=28800
```

Переменные и безопасные значения по умолчанию перечислены в `.env.example`.
Данные текущего подключения сохраняются в `reports/status.json` — эта папка
исключена из Git.

```bash
npm run check
npm test
npm audit --omit=dev
```

Зависимости зафиксированы lock-файлом. Override `uuid@11.1.1` устраняет известную
уязвимость в транзитивных версиях uuid; совместимость проверяется тестами и
реальным подключением. Все внешние Actions зафиксированы по commit SHA.
